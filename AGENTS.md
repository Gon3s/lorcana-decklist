# Consignes du projet

- Utiliser Oxlint pour le linting et Oxfmt pour le formatage.
- Ne pas utiliser les caractères Unicode U+2013 ou U+2014. Utiliser le trait d'union ASCII dans le code, les contenus, les données et la documentation.
- Ne pas introduire de taille de texte inférieure à 14 px. Préserver la lisibilité sur mobile.
- Le filtre des cartes doit accepter plusieurs encres. Par défaut, l'éditeur utilise les encres du deck.
- Le tri initial du catalogue est l'extension décroissante puis le numéro de collection croissant. Conserver les numéros propres aux réimpressions.
- Exécuter npm run lint, npm run check, npm test, npm run format:check et npm run build avant publication.
- Conserver la compatibilité des fiches et des catalogues déjà sauvegardés.
